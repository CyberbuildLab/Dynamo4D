# Dynamo Scripts for Rapid Location-Based Scheduling and 4D Modelling
Method and Dynamo scripts to rapidlly (highly automatically) generate construction schedules and 4D BIM models (i.e. 3D BIM model + schedule) given an input Revit model, a Location-Based Scheduling (LBS) strategy, and the general sequencing to be followed (at each location).

## Method:
The Method goes as follows:

1. Create a copy of the "4D-Modelling_Template.xlsx" file. It contains 5 tabs: *Shared_Parameters*, *Construction_Seq*, *Zone_Seq*, *Level_Seq* and *Generated_Schedule*. The last three are empty. The first is completed, and the second one just contains some example data.
2. Open Revit and open the 3D BIM Revit model with which you wish to generate a 4D model.
3. Open Dynamo Player, add the folder containing the scripts, and then open that folder. Dynamo Player should now list the 5 scripts
4. Run the script "1. Create 4D Modelling Shared Parameters". This requires you to provide the path to the "4D-Modelling_Template.xlsx" file. It then automatically creates four (Revit) Shared Parameters using the details contained in the *Shared_Parameters* tab in the Excel spreadsheet. Note that this step only needs to be conducted once on your Revit installation. The created Shared Parameters will then be available to add to any of your Revit projects.
5. Create for your current Revit project four *Project Parameters* as *Instance Parameters* by selecting the four 4D Modelling Shared Parameters that are now available. You can add the parameters to any Parameter Group, e.g. "Identity Data". Ensure the parameters are added to all element types that are within your 4D modelling scope.
6. In the Revit model create the necessary Grid Lines and subsequent Masses for the various Construction Zones that are part of your LBS strategy. The names are important and must be remembered. You could call them "A", "B", etc., or "Construction Zone A", "Construction Zone B", etc. 
7. If you have slabs or roofs that run across two or more of your construction zones, you will need to split them accordingly. You can do that manually, or run the script "2. Part and Divide Slabs" that enables you to select multiple slabs and/or roofs and simultaneously partition them according to one or more Grid Lines (i.e. the Grid Lines used to create the Construction Zone boundaries). Note that to be able to split slabs and roofs according to Grid Lines, Revit requires them to be first split into Parts. The script does that automatically for you.
8. If you have elements (walls, columns) that span multiple Levels that are part of your LBS strategy, then you must split them too. The same strategy as above can be used, but no script for this has been created yet (to come soon). So, you will have to do it manually, using Create Parts, and then Dividing Parts at the relevant Levels.
9. Run the script "3. Assign Construction_Zone Parameter Values". This will automatically identify which of the Revit model elements fall within each of the defined Construction Zones and set their "Construction Zone" parameter to the name of the Mass used to model that zone.
10. Run script "4. Collect Unique Zones and Levels". This creates the tables in the tabs *Zone_Seq* and *Level_Seq* in the "4D-Modelling_Template.xlsx" file. For each tab, it creates two columns with the first column containing all the Zones (resp. all the Levels) contained in the Revit model. The second column is not populated.
11. The reason why the second column of the tables above is not populated is because it is for you to decide and communicate to the sytesm in which order these should be considered in your LBS strategy. For example, if you have three zones (A, B and C) and want construction work to proceed from A to B to C, then enter "01", "02" and "03" in the respective cells in the second column.
12. Complete the table in the *Construction_Seq* tab of the "4D-Modelling_Template.xlsx" file. This table identifies the activities to repeated in each location of your LBS strategy. It is assumes that each activity relates to only one type of objects and these are identified by their Uniclass Code. Each line in the table corresponds to an activity and you must enter the Uniclass Code and Uniclass Description, the Production Rate in Hrs (i.e. number of hours per unit) and the Production Rate Unit (*item*, *square metre*, or *cubic metre*).
13. In your Revit model, ensure that the *Classification_Uniclass_No* Instance Parameters for the elements within your 4D modelling scope are set with the same Uniclass Codes as defined above. NOTE: In practice, one could expect those codes to be available as Type Parameters of the elements. If this is the case, then the script can easily be updated to consider those parameters instead. But, since we couldn't guarantee this, our method and scripts require the use of the dedicated *Classification_Uniclass_No* and *Classification_Uniclass_Description* created but the script 1. in Step 4 above.
14. Finally, run "5. Create Construction Sequencing and Final Schedule". This script now automatically does three things:
    1. It creates all necessary activities for the final schedule, considering the LBS strategies (zones and levels) and the construction sequence to be considered at each location. Each activity is provided a unique code "ZZLLAA" where "ZZ" and "AA" are the sequence numbers of the zone and level as defined in the "Zone_Seq" and "Level_Seq" tabs, and "AA" is the sequence number of the activity in the "Construction_Seq" tab.
    2. It populates the *4D_Task_ID* of each corresponding element with the final activity unique code defined above.
    3. It populates the "Generated_Schedule" tab of the "4D-Modelling_Template.xlsx" file with a table listing the final set of activities in sequential order, with their calculated Durations and Predecessors. Note that Durations are calculated automatically based on the Productivity Unit defined in the "Construction_Seq" tab as well as the number of hours per working day inputted by the user. That is, if the *Productivity Unit* is *item* and the number of hours per working day is 8, then the Duration is calculated by counting the number of elements associated to the activity, multiplied by the *Productivity Rate in Hours* and divided by 8. If the *Productivity Unit* is *cubic metre* then the Duration is calculated by calcuating the total volume of the elements associated to the activity, multiplied by the *Productivity Rate in Hours* and divided by 8.
